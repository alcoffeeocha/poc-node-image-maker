# POC Node Image Maker

## Tools under the hood

The script relies on some amazing Node.js libraries:

Generating PSD file

- [ag-psd](https://www.npmjs.com/package/ag-psd)
- [canvas](https://www.npmjs.com/package/canvas)

Generating SVG file

- [svg.js](https://svgjs.dev/docs/3.2/)
- [svgdom](https://www.npmjs.com/package/svgdom)

## Supported Layer Types

- Page background
- Image
- Text
